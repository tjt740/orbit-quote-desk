# ORBIT Quote Workspace

Bilingual product quotation workspace with 34 products and 72 initial plans. Prices are in CNY; empty VPN and IP pool prices remain pending.

- The nine catalog headers follow the supplied reference.
- Product groups expand into editable plan subtables.
- Text, numeric fields, dropdowns and multi-select tags are editable; custom columns support the same types.
- Add records to existing products or create products.
- Click to select a cell; double-click or press Enter/F2 to edit text and prices. Dropdowns and tags open beside the cell. Enter confirms and moves down, Tab moves across, and Escape cancels. Arrow keys navigate selected cells.
- Copy or paste cells, including tab-separated ranges from a spreadsheet. Range paste validates every value before applying it. Drag header edges to resize columns.
- Edits save automatically after a short pause. Undo/redo restores up to 40 changes and saves the restored result. **Save now** retries failed saves. D1 persists the catalog and the server update timestamp; revision checks protect simultaneous saves.
- Blue Ant Design theme plus light/dark themes, with no green accents. The title and last-update timestamp share a compact header; desktop summary cards are 68px high. Ant Design components power theme selection and product settings.
- Click the product image or settings icon to edit Chinese/English names and upload, replace or remove an image. PNG/JPG/WebP/GIF uploads are limited to 5 × 1024 × 1024 bytes by both client and server; the server validates the image signature and content type. Images persist in R2 while their keys and filenames persist with catalog metadata in D1.
- Uploaded and existing product images support drag/keyboard positioning, zoom, 90° rotation, square/4:3/16:9 crops and a live preview. Crops are bounded to 1024 pixels and saved as PNG; Use original preserves the source file, including GIF animation. Cancelling keeps the previous image.
- Option menus, keyboard editing, product settings and autosave status work in both languages. Visitors are read-only by default. Administrator sign-in unlocks editing, with server checks on catalog saves and image uploads. Sessions use HttpOnly, SameSite=Strict cookies (Secure on HTTPS), random session tokens stored as hashes in D1, an 8-hour expiry and immediate logout revocation. Password verification uses a salted PBKDF2 hash in the Site secret ORBIT_ADMIN_PASSWORD_HASH; ORBIT_ADMIN_USERNAME is also configured in Site secrets. Failed sign-in attempts are throttled; origin checks protect write operations. Site audience settings remain unchanged.
- The workspace focuses on the product catalog and per-product CNY/USD/MNT price tables. Quote creation, its navigation, selection toolbar, quantity/currency workflow and quote download have been removed. Catalog CSV export remains available. The sidebar starts with a smooth Three.js pelican riding a bicycle, with pedalling feet, spinning spokes, a moving neck and blinking eyes; there is no logo title or workspace card. The animation respects reduced-motion preferences.
- ExchangeRate-API reference rates are cached for one minute, queried every minute while open, and display their actual provider timestamp. The free source updates daily. Cached fallback is explicitly labeled; no invented fallback rates are used.
- Three.js orbital geometry and particles, interactive Canvas connections and animated gradients. A smooth 3D motorcycle racing game sits at the bottom of the desktop sidebar: hold WASD or arrow keys to move (W/up, A/left, S/down, D/right; both sets can be used together), hold Shift to use limited nitro, B to brake, J to punch, K to kick, Space to swing a stolen chain (or punch without one), and Escape to pause. The route crosses grassy plains with deciduous trees, pines, rocks and distant hills, then enters towns with houses, shops, sidewalks, lamps and crossings after 360 metres. Town and prairie sections recur along curved, hilly roads. Three races cover 1.2/1.5/1.8 km; finishing in the top three unlocks the next race. Six named rivals steer, retaliate, lose health and fall behind after knockdowns. Punching an armed rival steals their chain. Bicycles, motorcycles, cars, cargo trucks and tanks have distinct models, speeds and collision sizes; some traffic is oncoming. Collisions reduce rider stamina and bike condition; heavy impacts cause a timed fall and recovery while rivals keep racing. Aggressive combat brings a pursuing police rider: escape with nitro or risk being caught after a fall. Live HUD shows race position, distance, elapsed time, nearby rival health, stamina, condition and nitro. Results show placement, time, knockdowns and falls, with a full leaderboard when expanded. Optional synthesized engine/impact audio is muted by default. Expand the game for a larger play area. Keyboard controls are scoped to the focused game, which pauses on blur. MSAA plus 2–2.5× supersampling smooths the small canvas. Blue, violet, pink and amber accents distinguish categories, tags and statistics. Backgrounds respect reduced-motion preferences; hidden views skip game rendering.

## Development

`npm run dev -- --port 5174` starts the local preview. Generate schema-only D1 migrations using `npm run db:generate`, then apply local migrations per the Sites starter workflow. `npm run build` emits a Cloudflare-compatible Worker. The Sites workflow manages production migrations and deployment.

Catalog content is in `lib/catalog.ts`; application UI is in `app/page.tsx`, styling in `app/globals.css`, animations in `app/Atmosphere.tsx`. API routes are `app/api/catalog` and `app/api/rates`.
